# group-37
Sentence Builder CS Project 
Advisor: John Cole 
Group Members: Bianca, Cortland, Huy Nhat, Sebastian, Asher, Amrita

The goal of this project is to help students understand the inner workings of AI-like language tools by building a large-language-model system. The system ingests text files, constructs a word-frequency and bigram database, generates sentences based on learned patterns, and provides auto-complete suggestions. It also offers a GUI for exploring the word database, generating sentences, editing metadata, and viewing statistical reports.

Tech Stack:
Language- Java
GUI Framework: JavaFX
Database: MySQL
IDE: IntelliJ
